# EASE System - Quick Start Guide

## 🚀 GETTING STARTED

### Step 1: Open the Customer Website
Open this file in your browser:
```
index/index.html
```

The main EASE website will load with all features enabled.

## 👥 FOR CUSTOMERS (Main Website)

### Regular Purchase Flow:
1. **Click "Shop Collection"** or go to "SHOP" tab
2. **Browse Products** - See available jackets
3. **Click "Buy & Earn Points"** - Add item to order
4. **Click Shopping Bag Icon** (top right) - View cart
5. **Enter Details**: Name, Phone, Email
6. **Complete Order** - Order sent to admin!
7. **Track Points** - Badge shows your reward points

### VIP Unlock (At 500 Points):
- After earning 500 points, a special **VIP Obsidian Edition** unlock
- Shows as "ELITE MEMBER" tier
- Can purchase exclusive limited designs

### Bulk Orders:
1. Go to **"Bulk Orders"** tab
2. Enter quantity (minimum 20 pieces)
3. Select delivery location
4. **Click "Get Quotation"** - See discounted price
5. **Click "Register & Place Order"**
6. Fill registration form
7. Admin will contact within 24 hours

### Design Custom Jacket:
1. Go to **"Design"** tab (DESIGN STUDIO)
2. Choose jacket base color
3. Optionally add chest patch (+₱250)
4. Click "Submit Design"
5. Your quote will be sent!

## 📊 FOR ADMIN

### Step 1: Open Admin Dashboard
Open this file in your browser:
```
admin.html
```

### Step 2: Login
- **Username**: `admin`
- **Password**: `admin@EASE2026`

### Step 3: View Orders
You'll see the Dashboard with statistics:
- 📦 Total Orders
- 💰 Total Revenue  
- ⏳ Pending Orders
- 👥 Bulk Users

### Step 4: Manage Orders

**Click "Orders" tab to see all incoming orders:**

Each order shows:
- Order ID (e.g., ORD-1234567890)
- Customer name
- Order type (🛍️ Retail or 📦 Bulk)
- Amount
- Quantity
- Current Status
- Order date
- **"View" button** to see details

**To update order status:**
1. Click "View" on any order
2. See full customer info and items
3. Select new status from dropdown:
   - **Pending** → Not processed yet
   - **Confirmed** → Accepted & ready
   - **Shipped** → On the way
   - **Delivered** → Completed
   - **Cancelled** → Rejected
4. Click "Update Status"

### Step 5: Check Bulk Users

**Click "Bulk Users" tab:**
- See all registered bulk customers
- Name, Email, Phone, Location
- How many orders each customer placed
- Their total loyalty points

### Step 6: View Statistics

**Click "Statistics" tab:**
- Total revenue (largest number)
- Breakdown of retail vs bulk orders
- Average order value
- Total bulk users
- System points tracking

## 🆘 QUICK TROUBLESHOOTING

| Problem | Solution |
|---------|----------|
| Admin login not working | Check spelling (case-sensitive), clear browser cache |
| Orders not appearing | Refresh page, check browser storage enabled |
| Points not increasing | Make sure to click "Buy & Earn Points" button |
| Can't update order status | Select status first, then click Update |
| CSV won't download | Check if pop-ups are blocked in browser |
| Modal not opening | Refresh page or clear browser cache |
